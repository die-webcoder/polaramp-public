# polaramp – Rechtstexte

Öffentliche Rechtstexte der App **polaramp** (Datenschutzerklärung, Impressum, Lizenzen und rechtliche Hinweise).
Die Seiten werden über GitHub Pages veröffentlicht und im Google Play Store verlinkt:
https://die-webcoder.github.io/polaramp-public/

Die Texte werden nicht hier bearbeitet, sondern im App-Repository erzeugt (`tools/legal/export_legal.py`),
damit sie wortgleich mit den Texten in der App sind.
